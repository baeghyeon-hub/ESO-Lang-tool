## 1. 프로그램 소개

**ESO Lang Tool**은 ESO의 `.lang` 파일을 열어서 번역하고 저장하는 도구야.

### 이런 사람한테 필요해

- ESO 한글 패치를 직접 만들거나 수정하고 싶은 사람
- 기존 한글 패치 번역을 개선하고 싶은 사람
- 대량의 게임 텍스트를 효율적으로 관리하고 싶은 사람

### 주요 기능

- **117만 개 이상** 레코드 빠른 로딩·검색·편집
- 카테고리별 분류 (퀘스트, NPC, 아이템, 스킬 등)
- AI(Gemini/Claude/GPT) 자동 번역
- 용어집으로 고유명사 일관성 유지
- 기존 한글 패치 번역 재활용
- 수정 이력 추적, JSON 내보내기/가져오기

## 2. 시작하기

### 실행 방법

`ESO Lang Tool.exe`를 더블클릭하면 바로 실행돼.

> 별도 설치 과정 없이 exe 파일만 있으면 바로 쓸 수 있어.

실행하면 다크 테마의 빈 화면이 나타나.

## 3. 파일 열기

상단 메뉴에서 **파일(F) > 열기**를 클릭하거나 **Ctrl+O**를 눌러.

![파일 메뉴](screenshot/1.png)
*▲ 파일 메뉴 — 열기, 저장, 내보내기, 가져오기 등이 있어.*

### 어떤 파일을 열어야 해?

| 파일 | 설명 |
|------|------|
| `kr.lang` | 한글 패치 파일 — 주로 이걸 열어서 번역 작업해 |
| `en.lang` | 영어 원본 파일 — 참고용으로 자동 연결돼 |

### 로딩 화면

파일을 선택하면 자동으로 로딩이 시작돼. 117만 개 레코드를 읽어들이는 과정이 진행률과 함께 표시돼.

![로딩 진행률](screenshot/2.png)
*▲ 레코드 로딩 중 — 117만 개 레코드를 읽어들이는 중. 보통 몇 초면 끝나.*

> 로딩 중에 **취소** 버튼 누르면 중단할 수 있어.

### 코덱 자동 감지

- `en.lang` → Identity (변환 없음)
- 기존 한글 패치 파일 → **KR Legacy** (한글 인코딩 자동 변환)

코덱은 하단 상태바에서 확인 가능하고, **보기(V) > 텍스트 코덱**에서 수동 전환도 돼.

## 4. 화면 구성

파일을 열면 이런 화면이 나와.

![메인 화면](screenshot/3.png)
*▲ 메인 화면 — 왼쪽에 카테고리 트리, 오른쪽에 레코드 테이블, 아래에 편집 패널이 있어.*

### 각 영역 설명

#### ① 상단 툴바
- **열기 / ← 뒤로 / 검색** 버튼
- **정규식** 체크박스, **상태 필터** 드롭다운

#### ② 검색바
- 키워드 입력하면 실시간으로 검색돼 (FTS5 전문 검색)
- 정규식 모드 켜면 패턴 검색도 가능해

#### ③ 왼쪽 카테고리 트리
게임 데이터를 카테고리별로 분류해서 보여줘:

| 카테고리 | 설명 | 대략적 건수 |
|----------|------|------------|
| 퀘스트 | 퀘스트 대사, 설명 | ~73,000 |
| NPC | NPC 이름 | ~79,000 |
| 스킬 | 스킬 이름, 설명 | ~107,000 |
| 아이템 | 아이템 이름, 설명 | ~197,000 |
| 업적 | 업적 이름, 조건 | ~25,000 |
| 수집품 | 수집품 이름, 설명 | ~46,000 |
| 장소 | 지역, 던전 이름 | ~15,000 |
| 로어 | 로어북 본문 | ~14,000 |
| 기타 | 위에 안 속하는 항목 | ~11,000 |
| 미분류 | 카테고리 미매핑 항목 | ~247,000 |

카테고리 클릭하면 해당 항목만 테이블에 표시돼.

#### ④ 오른쪽 레코드 테이블
| 열 | 설명 |
|----|------|
| ID | 레코드 고유 ID (카테고리 구분용) |
| Unknown | 게임 내부 플래그 (0 또는 1) |
| Index | 같은 ID 안에서의 순번 |
| Source | 원문 텍스트 (영어 또는 기존 번역) |
| Target | 번역문 — 여기에 한국어 입력 |

#### ⑤ 하단 편집 패널
테이블에서 행을 선택하면 아래쪽에 편집 패널이 뜨는데:
- **Source (원문)**: 읽기 전용 — 원문 확인용
- **Target (번역)**: 여기에 번역 입력하면 돼

#### ⑥ 하단 탭
- **편집**: 기본 편집 패널
- **번역**: AI 자동 번역 패널
- **용어집**: 용어집 관리 패널

#### ⑦ 상태바 (맨 아래 노란색 바)
현재 파일 정보가 한눈에 보여:
- 파일명, 코덱, 수정 건수
- 번역 진행률 (행 기준 / 원문 기준)
- 전체 레코드 수

## 5. 검색 및 필터

### 키워드 검색

1. 상단 검색창에 검색어 입력 (또는 **Ctrl+F**)
2. 입력하는 즉시 실시간으로 결과가 필터링돼
3. Source랑 Target 모두에서 검색해

> **팁:** 정규식 체크 켜면 `^The.*Castle$` 같은 패턴 검색도 돼.

### 상태 필터

검색창 오른쪽 드롭다운에서 원하는 상태를 골라:

| 필터 | 설명 |
|------|------|
| **전체** | 전부 다 보여줌 |
| **미번역만** | Target이 비어있는 것만 |
| **번역됨** | Target이 채워진 것만 |
| **수정됨** | 이번 작업에서 수정한 것만 |
| **기존 번역 있음** | 기존 한패(kr.lang)에 번역이 있는 미번역 레코드 |

> **핵심:** 카테고리 + 키워드 검색 + 상태 필터는 **동시에 적용**돼.
> 예시: 왼쪽에서 "NPC" 선택 → 검색창에 "Razum" → 필터 "미번역만" → NPC 중 Razum 포함된 미번역만 표시

### 다음 미번역으로 이동

**F3** 누르면 다음 미번역 레코드로 자동 이동해. 순서대로 번역할 때 편해.

## 6. 번역 편집

### 단일 행 편집

1. 테이블에서 번역할 행 클릭
2. 하단 편집 패널의 **Source**에서 원문 확인
3. **Target** 칸에 번역 입력
4. 다른 행 클릭하면 자동 저장돼

### 여러 행 한꺼번에 편집

같은 번역을 여러 행에 적용할 때 쓰면 돼 (예: 같은 NPC 이름).

1. **Ctrl+클릭** 또는 **Shift+클릭**으로 여러 행 선택
2. 하단 편집 패널이 **일괄 편집 모드**로 바뀜
3. 번역 입력하고 **"N개에 적용"** 버튼 클릭

### 실행 취소 / 다시 실행

- **Ctrl+Z**: 방금 한 편집 취소
- **Ctrl+Y**: 취소한 거 다시 적용

> 최대 200단계까지 되돌릴 수 있어.

### 찾기 / 치환

특정 단어를 일괄 교체할 때 써.

1. **Ctrl+H** 누르기
2. 찾을 내용이랑 바꿀 내용 입력
3. 범위 선택 (현재 필터 결과 또는 전체)
4. **모두 치환** 클릭

> 치환은 Ctrl+Z로 한 번에 되돌릴 수 있어.

## 7. 우클릭 메뉴

테이블에서 행을 우클릭하면 유용한 기능들이 나와.

![우클릭 메뉴](screenshot/7.png)
*▲ 우클릭 메뉴 — 참조 번역 보기, 같은 문자열 모으기, 번역 대상 지정 등을 할 수 있어.*

### 주요 메뉴

| 메뉴 | 설명 |
|------|------|
| **참고 Source 번역 보기** | 같은 원문의 기존 번역 확인 |
| **같은 Source에 쓰기** | 같은 원문 가진 모든 행에 같은 번역 적용 |
| **같은 Source만 보기** | 같은 원문 가진 행만 필터링 |
| **같은 Source 행 모두 선택** | 같은 원문 가진 행 전부 선택 |
| **번역 대상 지정 (N건)** | 선택한 행을 AI 번역 큐에 추가 |
| **선택 행 내보내기 (N건)** | 선택한 행을 JSON으로 내보내기 |

### "참고 Source 번역 보기" 활용법

같은 영어 원문이 다른 곳에서 어떻게 번역됐는지 볼 수 있어:

1. 행 우클릭 → **참고 Source 번역 보기**
2. 팝업에서 기존 번역 후보 확인
3. 맘에 드는 번역 선택 → **"선택 번역 입력"** 클릭
4. 자동으로 같은 원문 행이 선택되고 번역이 채워져

## 8. 용어집

NPC 이름, 아이템 이름 같은 고유명사의 번역 일관성을 유지하는 기능이야.

### 용어집 탭 열기

하단의 **용어집** 탭 클릭하거나 **Ctrl+G** 눌러.

![용어집 패널](screenshot/4.png)
*▲ 용어집 패널 — 용어 추출, 기존 번역 채우기, 가져오기/내보내기가 있어.*

### 용어 추출

1. `.lang` 파일을 열어둔 상태에서 **용어 추출** 버튼 클릭
2. 로드된 데이터에서 고유명사 후보를 자동 추출해

![용어 추출 결과](screenshot/5.png)
*▲ 용어 추출 완료 — 추출된 용어 수, 카테고리별 통계가 나와.*

추출 끝나면 용어집 테이블에 결과가 채워져:

![용어집 채워진 모습](screenshot/6.png)
*▲ 추출된 용어집 — 용어(EN), 번역(KR), 카테고리, 성별, 사용 수가 표시돼.*

### 용어집 테이블 열 설명

| 열 | 설명 |
|----|------|
| **용어 (EN)** | 영어 고유명사 |
| **번역 (KR)** | 한국어 번역 (더블클릭해서 직접 편집 가능) |
| **카테고리** | NPC, ITEM, SKILL 등 자동 분류 |
| **성별** | 게임 내 성별 마커 (^F, ^M, ^N) |
| **사용 수** | 게임 데이터에서 해당 용어가 쓰인 횟수 |
| **메모** | 자유롭게 메모 남길 수 있어 |

### 기존 번역 채우기

용어 추출 후, 기존 한패에 이미 번역이 있는 용어를 자동으로 채워넣을 수 있어:

1. **기존 번역 채우기** 버튼 클릭
2. 레코드의 Target에서 번역을 가져와서 빈 용어집 번역을 자동으로 채워줘

### 용어집 내보내기 / 가져오기

- **내보내기**: 용어집을 JSON 파일로 저장
  - **단일 JSON**: 전체 용어집을 하나의 파일로
  - **카테고리별 JSON**: 폴더 선택하면 NPC, 아이템 등 카테고리별로 분리 저장
- **가져오기**: JSON 파일에서 용어집 불러오기 (기존 항목은 업데이트, 새 항목은 추가)

### 용어집 + AI 번역 연동

용어집에 번역이 등록된 고유명사는 AI 번역할 때 자동으로 프롬프트에 포함돼.
AI가 "Razum-dar"를 "라줌다르"로 일관되게 번역하도록 유도하는 거야.

## 9. AI 자동 번역

선택한 레코드를 AI(Gemini, Claude, GPT)로 자동 번역할 수 있어.

### 번역 대상 지정

1. 테이블에서 번역할 행 선택 (Shift/Ctrl로 여러 행 가능)
2. 우클릭 → **번역 대상 지정 (N건)**
3. 하단 **번역** 탭으로 자동 이동

### API 키 설정

AI 번역 쓰려면 먼저 API 키를 설정해야 해:

1. 메뉴 **번역(T) > API 키 설정** 클릭
2. 쓸 프로바이더(Gemini/Claude/GPT)의 API 키 입력

### 번역 실행

1. **번역** 탭에서 프로바이더랑 모델 선택
2. 배치 크기 설정 (기본 20건)
3. **번역 시작** 버튼 클릭
4. 진행률 표시와 함께 번역이 진행돼

### 품질 검증

AI 번역 결과는 자동으로 이런 항목들을 체크해:

| 검증 항목 | 설명 |
|-----------|------|
| 빈 번역 | 번역 결과가 비어있는지 |
| 영어 그대로 | 원문이랑 똑같은지 |
| 한국어 비율 | 한국어가 30% 미만인지 |
| 길이 비율 | 원문 대비 너무 짧거나(0.2배) 길지(3배) 않은지 |
| 플레이스홀더 | `<<1>>` 같은 변수가 빠지지 않았는지 |

## 10. 내보내기 / 가져오기

번역 데이터를 JSON 파일로 주고받을 수 있어. 다른 사람이랑 협업하거나 백업할 때 유용해.

### 내보내기 종류

| 메뉴 | 단축키 | 설명 |
|------|--------|------|
| **선택 행 내보내기** | Ctrl+Shift+E | 지금 선택한 행만 |
| **현재 필터 내보내기** | — | 현재 검색/필터 결과 전체 |
| **내가 수정한 항목만 내보내기** | Ctrl+Shift+T | 이 도구에서 수정한 레코드만 |
| **en.lang 비교 내보내기** | Ctrl+Shift+D | 번역된 전체 항목 |

### 가져오기

1. **파일(F) > 번역 가져오기** 또는 **Ctrl+Shift+I**
2. JSON 파일 선택
3. 가져오기 모드 선택:
   - **target 필드 사용**: 일반 번역 가져오기
   - **source 필드 사용**: 영어 원문 복원할 때
4. 변경 내용 확인하고 적용

### 협업 예시

```
작업자 A: kr.lang 열기 → 번역 → 저장
         → "내가 수정한 항목만 내보내기" → JSON 공유

작업자 B: kr.lang 열기 → "번역 가져오기" → JSON 적용 → 저장
```

## 11. 저장

### 일반 저장

- **Ctrl+S** 또는 **파일(F) > 저장**
- 첫 저장은 경로 선택 창이 뜸
- 이후부턴 같은 경로로 바로 저장

### 다른 이름으로 저장

- **Ctrl+Shift+S** 또는 **파일(F) > 다른 이름으로 저장**
- 원본 보존하고 싶을 때 써

### 저장하면 이런 일이 일어나

1. 현재 DB의 모든 레코드를 `.lang` 바이너리로 변환
2. 중복 문자열은 자동으로 합쳐서 파일 크기 최적화
3. `.lang.mod.json` 파일에 수정 이력 저장

> **수정 이력**은 프로그램 껐다 켜도 유지돼. 다음에 같은 파일 열면 이전에 수정한 항목이 자동으로 표시돼.

## 13. FAQ

### 파일 열었는데 한글이 깨져

**보기(V) > 텍스트 코덱**에서 **KR Legacy** 선택해봐. 기존 한패 파일은 특수한 인코딩을 쓰거든.

### en.lang이랑 kr.lang 동시에 열 수 있어?

메인으로 한 파일 열면, 같은 폴더에 있는 다른 `.lang` 파일은 참고용으로 자동 연결돼. 우클릭 → "참고 Source 번역 보기"에서 영어 원문이랑 기존 한글 번역을 같이 확인할 수 있어.

### 수정한 거 실수로 날렸어

- **Ctrl+Z**로 되돌릴 수 있어 (최대 200단계)
- 저장 안 했으면 파일 다시 열면 원래 상태로 돌아가
- 저장했더라도 `.lang.mod.json` 파일에 수정 이력이 남아있어

### AI 번역 쓰면 돈 들어?

AI 번역은 외부 API를 쓰는 거라 각 프로바이더(Google Gemini, Anthropic Claude, OpenAI GPT) 요금 정책에 따라 비용이 발생할 수 있어. 본인 API 키를 등록해서 써.

### 번역한 파일을 게임에 적용하려면?

저장된 `.lang` 파일을 게임 해당 경로에 넣으면 돼. 자세한 적용법은 ESO 한글 패치 커뮤니티 참고해.

### 기존 한패 번역을 한꺼번에 가져올 수 있어?

**번역(T) > 기존 번역 일괄 적용** (Ctrl+Shift+R) 써. 기존 kr.lang에서 번역된 내용을 현재 파일에 일괄 적용해줘. 이미 번역 있는 항목은 안 건드려.
