# ESO .lang 바이너리 포맷

## 개요

ESO(Elder Scrolls Online)의 `.lang` 파일은 게임 내 모든 텍스트(대사, UI, 아이템명 등)를
저장하는 바이너리 파일이다. 파일 하나에 100만+ 레코드가 포함된다.

## 파일 구조

```
[Header: 8 bytes]
[Records: N × 16 bytes]
[Text Blob: 나머지 전부]
```

### 헤더 (8 bytes, Big-Endian)

| 오프셋 | 크기 | 필드 | 값 |
|--------|------|------|-----|
| 0 | 4B | version | 2 (고정) |
| 4 | 4B | record_count | 레코드 수 |

### 레코드 (16 bytes × N, Big-Endian)

| 오프셋 | 크기 | 필드 | 설명 |
|--------|------|------|------|
| 0 | 4B | id | 카테고리 ID (449종류) |
| 4 | 4B | unknown | 용도 미확인 (보통 0 또는 1) |
| 8 | 4B | idx | 레코드 인덱스 |
| 12 | 4B | offset | 텍스트 blob 내 바이트 오프셋 |

### 텍스트 Blob

- 인코딩: UTF-8
- 구분자: NUL (0x00) 종단
- 중복 문자열은 같은 offset을 공유 (dedup)

## 실측 데이터 (en.lang)

| 항목 | 값 |
|------|-----|
| 파일 크기 | 69,029,377 bytes (~66MB) |
| 레코드 수 | 1,167,734 |
| 고유 ID 수 | 449 |
| 고유 문자열 | 558,295 (중복률 52.2%) |
| 텍스트 영역 | ~48MB |

## KR Legacy 인코딩 (kr.lang)

기존 ESO 한글패치(EsoKR)의 kr.lang은 한글을 CJK 코드포인트로 치환하여 저장한다.
게임 클라이언트의 폰트 시스템 제약을 우회하기 위한 방법이다.

### 코드포인트 매핑

| 한글 범위 | 저장 범위 | 오프셋 |
|:----------|:----------|:-------|
| U+1100~U+11FF (자모) | U+5E00~U+5EFF | +0x4D00 |
| U+3131~U+318F (호환 자모) | U+5F01~U+5F5F | +0x2DD0 |
| U+AC00~U+D7A3 (음절) | U+6E00~U+99A3 | -0x3E00 |

디코딩(파일→표시): CJK → 한글 (역방향 오프셋)
인코딩(표시→파일): 한글 → CJK (정방향 오프셋)

### kr.lang 특이사항

- 원본 kr.lang은 문자열 dedup이 안 되어 있음 (591,079개 중복)
- 빌더가 dedup을 적용하면 파일 크기가 줄어듦 (100MB→83MB)
- 기능적으로 동일하나 바이트 동일은 불가
