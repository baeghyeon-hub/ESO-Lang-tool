# ESO Lang Tool 사용법

## 실행

```powershell
$env:PYTHONIOENCODING="utf-8"
C:\Users\user\AppData\Local\Programs\Python\Python311\python.exe main.py
```

## 파일 열기

1. `파일 > 열기` 또는 `Ctrl+O`
2. `.lang` 파일 선택
3. 코덱 자동 감지
   - `en.lang`: `Identity`
   - 기존 KR 패치: `ESO KR Legacy`

`보기 > 텍스트 코덱`에서 수동 전환도 가능합니다.

## 검색과 필터

### 검색

- `Ctrl+F`로 검색창 포커스 이동
- FTS5 기반 실시간 검색
- `정규식` 체크 시 Python `re` 기준 검색

### 상태 필터

- `전체`
- `미번역만`
- `번역됨`
- `수정됨`
- `기존 번역 있음` — 레퍼런스 DB(kr.lang)에 번역이 존재하는 미번역 레코드만 표시

현재 그룹, 검색 결과, 상태 필터는 함께 적용됩니다.

### 같은 문자열 모으기

테이블에서 우클릭하면 아래 기능을 바로 쓸 수 있습니다.

- `같은 Source만 보기`
- `같은 Source 행 모두 선택`
- `같은 Target만 보기`
- `같은 Target 행 모두 선택`

`Ctrl+Shift+F`로 문자열 포커스를 해제할 수 있습니다.

## 편집

### 단일 편집

- 하단 `Target` 편집창에서 바로 수정
- 포커스를 벗어나면 자동 커밋
- `Ctrl+Z`, `Ctrl+Y`로 Undo / Redo

### 다중 선택 일괄 편집

- 테이블에서 `Shift` 클릭, `Ctrl` 클릭으로 여러 행 선택
- 하단 편집 패널이 자동으로 일괄 편집 모드로 전환
- 공통 번역문을 입력한 뒤 `N개에 적용`
- 다중 선택 상태에서 텍스트를 바꾸고 다른 행으로 이동해도 변경 내용은 자동 반영됩니다

### 기존 번역 보기

- 단일 행 선택 시 하단의 `기존 번역 보기` 버튼 사용
- 또는 우클릭 메뉴의 `같은 Source 번역 현황 보기`

조회창 동작:

- 현재 편집본의 `Target` 번역문
- 현재 파일의 `Source` 번역 변형
- 기존 KR 패치 참조 번역문
- `kr.lang`을 열어둔 경우에도 `en.lang` 기준 원문 묶음으로 다시 연결해 후보를 계산
- 한글 번역 후보가 있으면 원문과 동일한 영어 후보는 뒤로 밀리거나 숨겨집니다

조회창에서 `선택 번역 입력`을 누르면:

- 같은 `Source` 행이 자동 선택됨
- 하단 편집 패널이 바로 일괄 편집 상태로 전환됨
- 선택한 번역문이 `Target` 편집칸에 미리 채워짐

## 기존 번역 일괄 적용

레퍼런스 DB(kr.lang)에 이미 번역된 내용을 한번에 Target에 적용합니다.

### 사용법

1. `번역 > 기존 번역 일괄 적용` (`Ctrl+Shift+R`)
2. 적용 가능 건수 확인 후 "Yes"
3. 미번역 레코드에만 적용 (이미 Target이 있는 항목은 보존)

### 필터로 미리 확인

- 검색바 필터에서 `기존 번역 있음` 선택
- 레퍼런스에 번역이 있는 미번역 레코드만 테이블에 표시
- 일괄 적용 전에 어떤 항목이 대상인지 확인할 수 있습니다

### 동작 원리

- 현재 DB와 레퍼런스 DB(kr.lang)를 `(id, unknown, idx)` 키로 크로스 매칭
- 레퍼런스의 source가 현재 source와 다르면 번역이 존재하는 것으로 판단
- 적용된 레코드는 `modified=1` 플래그가 자동 설정됨

## 번역 대상 지정 + LLM 번역

### 큐 기반 워크플로우

1. 테이블에서 행을 선택 (Shift/Ctrl 다중 선택 가능)
2. 우클릭 → `번역 대상 지정 (N건)`
3. 하단 `번역` 탭으로 이동
4. 큐 상태 확인 (미번역 건수, 고유 source 수, 예상 API 호출)
5. Provider/Model/배치 크기 설정 후 `번역 시작`

### 번역 대상 해제

- 우클릭 → `번역 대상 해제 (N건)`
- 번역 탭의 `대상 초기화` 버튼

### API 키 설정

- `번역 > API 키 설정` 메뉴 또는 번역 탭의 `API 키 설정` 버튼
- Gemini / Claude / GPT 프로바이더별 키 입력

## 내보내기 / 가져오기

### 선택 행 내보내기

- 테이블에서 행 선택 → `파일 > 선택 행 내보내기` (`Ctrl+Shift+E`)
- 또는 우클릭 → `선택 행 내보내기 (N건)`
- JSON 형식으로 저장:
  ```json
  [
    {"id": 242841564, "unknown": 0, "idx": 0, "source": "Hello", "target": "안녕"},
    ...
  ]
  ```

### 현재 필터 내보내기

- `파일 > 현재 필터 내보내기`
- 현재 그룹/검색/상태 필터에 표시된 레코드 전체를 JSON으로 내보내기

### 내가 수정한 항목만 내보내기

- `파일 > 내가 수정한 항목만 내보내기` (`Ctrl+Shift+T`)
- 이 툴에서 수정한 레코드(`modified=1`)만 JSON으로 내보내기
- en.lang이 있으면 source를 영어 원문으로 자동 교체
- 수정 이력은 `.lang.mod.json` 사이드카 파일로 세션 간 보존됨

### en.lang 비교 내보내기 (전체 번역분)

- `파일 > en.lang 비교 내보내기` (`Ctrl+Shift+D`)
- en.lang과 kr.lang의 source를 비교하여, 다른 항목(=번역된 항목) 전체를 내보내기
- 한패 전체 번역분을 공유할 때 유용

### 번역 가져오기

- `파일 > 번역 가져오기` (`Ctrl+Shift+I`)
- 가져오기 모드 선택:
  - **target 필드 사용**: 일반 번역 가져오기
  - **source 필드 사용**: 영어 원문을 Target에 덮어쓰기 (한글→영어 복원)
- `(id, unknown, idx)` 키로 매칭, 변경 확인 후 적용
- Undo로 되돌리기 가능

### 공유 워크플로우

1. kr.lang에서 번역 작업 후 저장
2. `파일 > 내가 수정한 항목만 내보내기` → `modified_export.json`
3. JSON 파일을 다른 작업자에게 공유
4. 받는 쪽: `파일 > 번역 가져오기` → target 필드 사용 → 적용

## 용어집

### 용어집 열기

- `편집 > 용어집` (`Ctrl+G`) 또는 하단 탭의 "용어집" 클릭

### 용어 추출

- "용어 추출" 버튼 클릭
- en.lang에서 영어 term, kr.lang에서 한글 translation을 `(id, unknown, idx)` 키로 매칭
- 기존 용어집이 있으면 "초기화 후 재추출" 또는 "추가 추출" 선택 가능

### 기존 번역 채우기

- "기존 번역 채우기" 버튼: records의 target → 빈 glossary translation 자동 채움

### 용어집 import/export

- "내보내기" — 형식 선택:
  - **단일 JSON (전체)**: 전체 용어집을 하나의 JSON 파일로 저장
  - **카테고리별 JSON (폴더)**: 폴더를 선택하면 카테고리별로 영>한 쌍번역 파일 생성
    - 예: `glossary_npc.json`, `glossary_item.json`, `glossary_skill.json` ...
    - 각 파일 형식:
      ```json
      {
        "category": "NPC",
        "description": "NPC 이름",
        "count": 1234,
        "terms": [
          {"en": "Razum-dar", "kr": "라줌다르"},
          {"en": "Abnur Tharn", "kr": "아브너 탄"}
        ]
      }
      ```
    - 번역이 있는 항목만 내보냄
- "가져오기" → JSON에서 UPSERT (기존 항목 갱신, 새 항목 추가)

### LLM 번역 연동

- 용어집의 `translation` 필드가 LLM 번역 프롬프트에 자동 포함
- "Glossary (use these exact translations)" 섹션으로 전달

## 찾기 / 치환

- `Ctrl+H`
- `Target` 컬럼의 비어있지 않은 텍스트만 치환
- 범위 선택
  - 현재 필터 결과
  - 전체 레코드
- 한 번의 치환은 Undo 1단계로 묶입니다

## 저장

### 저장

- `Ctrl+S`
- 첫 저장은 저장 경로 선택
- 이후 같은 경로로 저장

### 다른 이름으로 저장

- `Ctrl+Shift+S`
- 출력 파일명을 새로 지정

## 상태바

하단 상태바에는 아래 정보가 표시됩니다.

- 현재 파일명
- 현재 코덱
- 수정 건수 / 수정 글자 수
- 현재 필터 범위 진행률
- 전체 행 기준 번역률
- 전체 원문 기준 번역률
- 현재 레코드 수 / 전체 레코드 수

가독성을 위해 상태바는 노란 배경과 검은 글씨 테마로 표시됩니다.

## 수정 이력 추적

- 이 툴에서 번역을 수정하면 자동으로 `modified=1` 플래그가 기록됩니다.
- 파일 저장 시 `.lang.mod.json` 사이드카 파일에 수정된 레코드 키가 저장됩니다.
- 파일을 다시 열면 사이드카 파일에서 이력이 자동 복원됩니다.
- 여러 세션에 걸쳐 이력이 누적 병합됩니다.
